## 2. Nhánh 1 — Dashboard Marketplace (đã live)

### Việc đã làm

- `GET /api/kinh-doanh/tong-quan-kenh` — doanh thu tách theo sàn, so kỳ trước
- `GET /api/kinh-doanh/xep-hang-sku` — 10 SKU bán chạy + 10 bán kém
- `POST /api/kinh-doanh/tach-dong-hang` — bóc bù dòng hàng (chỉ Admin)
- Bảng `don_hang_item` + `migrations/them-donhang-dong.sql`
- **Đã xoá** API cũ `tong-quan-doanh-thu` và metric `doanh_thu_hom_nay`

### 5 lỗi tìm được — đọc để không lặp lại

1. **Thẻ "Doanh thu hôm nay" trên Home chưa từng hiện lần nào.** `app.js` gọi
   `API.kdTongQuanDoanhThu()` mà `api.js` không hề định nghĩa hàm đó →
   `TypeError` rơi vào `catch {}` rỗng. **Bài học: `catch` rỗng nuốt im lặng
   là thứ che lỗi lâu nhất.** Chỗ đó nay bắt buộc `console.error`.
2. **Tiền lưu ×100000** (`migrations/them-donhang.sql`). Quên chia là sai gấp
   100.000 lần. Các API MỚI trong khối Tổng quan 2 sàn trả thẳng VNĐ đã chia
   sẵn — **đừng chia lại lần nữa**.
3. **Giá mặt hàng ≠ doanh thu.** Shopee `model_discounted_price` mới trừ giảm
   giá của NGƯỜI BÁN, voucher sàn ở cấp đơn → tổng giá dòng cao hơn
   `total_amount` **16,4%** (đo trên 150 đơn thật). TikTok `total_amount` lại
   **cộng cả phí ship** (0,9%). Vì vậy doanh thu SKU là **phân bổ** từ
   `tong_tien` theo tỷ lệ giá trị dòng — 300/300 đơn thật khớp tuyệt đối.
4. **TikTok `line_items` = mỗi phần tử 1 ĐƠN VỊ hàng**, không có trường số
   lượng. Phải gộp theo SKU rồi mới đếm. Shopee thì ngược lại, mỗi phần tử là
   1 dòng đã có sẵn số lượng.
5. **So sánh "kỳ trước" phải dịch lùi 1 bước tự nhiên của kỳ**, không phải
   "cửa sổ liền trước cùng độ dài" — lúc 9h sáng thì cách sau cho ra 9 tiếng
   CUỐI ngày hôm qua, khung giờ mua hàng khác hẳn.

### Còn treo trên nhánh này

- **Danh mục sản phẩm production đang TRỐNG** (`san_pham` 0 dòng) → "10 SKU
  bán kém nhất" hiện chỉ xếp trong số mã ĐÃ bán; mã bán 0 cái chưa hiện được.
  Nhập danh mục vào Kho vận là tự đủ, không cần sửa code.
- **Nút bóc bù chưa chạy**: còn ~24.000 đơn chưa tách dòng hàng. Admin vào
  tab Kinh doanh, bấm dòng cảnh báo vàng ở khối "Sản phẩm bán chạy & bán kém".
- **TikTok tính cả phí ship vào doanh thu** (lệch 0,9% so với Shopee). Sửa
  được (`payment.sub_total`), backfill từ `du_lieu_json`, nhưng đổi ý nghĩa
  số đã lưu của 3.103 đơn → **chờ ERP Owner quyết**.
- **Tỷ lệ hủy Shopee tháng 9 là 10,4%** giá trị đơn đặt. Ngưỡng cảnh báo đang
  để 10% nên sẽ kêu mỗi lần mở → cần ERP Owner xác nhận mức bình thường của
  ngành để chỉnh ngưỡng.

## 5. Nếu cần sửa/deploy

```
git fetch origin && git checkout -b fix/<mô-tả> origin/main
# sửa code
node --check public/assets/js/app.js && node --check src/index.js
git push -u origin fix/<mô-tả>
```

Deploy = **merge vào `main`**, GitHub Actions tự đẩy lên Cloudflare. Không
`wrangler deploy` tay từ máy cá nhân.

Có file `.sql` mới trong `migrations/` thì **ngay sau khi deploy**:

```
node scripts/chay-migration.mjs <tên-file.sql> --remote
```

Chạy 2 lần sẽ báo `duplicate column` — **vô hại**, nghĩa là đã chạy rồi.
Kiểm bằng: `SELECT * FROM schema_migrations WHERE filename='<tên-file.sql>'`.

⚠️ Máy Windows: PowerShell chặn `npx.ps1`. Gõ **`npx.cmd`** thay cho `npx`,
hoặc `node node_modules\wrangler\bin\wrangler.js`.
